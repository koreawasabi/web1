          ABOUT THIS TOOL

          히오스 전략 코치 사용 안내

          히오스 전략 코치는 경기 중 흩어진 정보를 한곳에 정리해, 지금 확인할 만한 다음 행동을 제안하는 무료 한국어 도구입니다. 전장별 목표와 밴픽을 준비 화면에서 기록하고, 경기 중에는 게임 시간·오브젝트·양 팀의 생존·레벨을 입력해 운영 판단의 참고 자료로 활용할 수 있습니다.

          1. 전장과 밴픽 기록

          전장을 고르면 맵의 목표와 라인 구조를 고려한 참고 영웅 안내가 표시됩니다. 검색으로 영웅을 선택하고 밴·픽을 기록한 뒤 새 경기를 시작하세요. 맵별 안내는 조합이나 숙련도를 대신하는 정답이 아닙니다.

          2. 게임 시계 시작

          전황 화면에서 게임 시작을 누르면 로컬 경기 시계가 작동합니다. 실제 게임과 시각이 다르면 일시정지·시간 보정 기능을 사용하세요. 앱은 게임 클라이언트와 연결되지 않으므로 자동으로 시간을 맞추지 않습니다.

          3. 확인한 상황만 입력

          오브젝트 경합, 사망 인원, 레벨과 부활 시간을 아는 범위에서 입력하세요. 영웅별 상태와 팀 전체 사망 수를 함께 쓸 때는 중복 계산을 줄이도록 더 큰 확인 수를 반영합니다.

          4. 추천을 확인하고 직접 판단

          추천 카드에서 우선 행동과 판단 근거를 먼저 확인하고, 필요하면 실행 조건·주의 사항·대안을 펼쳐 보세요. 실제 시야, 적 위치, 체력·마나, 오브젝트 진행도는 직접 확인해야 합니다.

          HOW RECOMMENDATIONS WORK

          추천 기준과 데이터의 한계

          추천은 경기 입력과 공개된 전장 규칙을 조합하는 브라우저 내 규칙 기반 분석입니다. 생존 인원과 부활 시점, 특성 구간, 다음 오브젝트까지의 시간, 사용자가 입력한 맵 고유 상태를 함께 고려합니다. 확인되지 않은 정보를 임의로 채우지 않으며, 정보가 모자라면 안전 확인이나 추가 입력을 우선 안내합니다.

          오브젝트와 합류

          맵에 따라 알려진 첫 목표 및 반복 규칙을 참고하되, 고정 시각을 확인할 수 없는 목표는 직접 입력이 필요합니다. 남은 시간만으로 적의 위치나 목표 진행 상황을 추정하지 않습니다.

          상황에 맞춘 운영

          확인된 인원 우위와 한타 결과가 있으면 목표·캠프·라인 교환을 검토하고, 조건이 불명확하거나 불리하면 무리한 진입을 피하도록 안내합니다. 안전한 교환 여부는 사용자가 직접 확인해야 합니다.

          승률 분석이 아닙니다

          이 도구는 실제 경기 기록, 승률 통계, 영웅 조합 시뮬레이션 또는 게임 클라이언트 연동을 제공하지 않습니다. 영웅·맵별 설명은 일반적인 운영 참고이며 패치와 플레이 상황에 따라 달라질 수 있습니다.

          사용자가 통제하는 저장

          입력한 경기 상태는 같은 브라우저에서 이어서 쓰도록 기기의 브라우저 저장 공간에 보관됩니다. 입력 초기화 또는 브라우저 사이트 데이터 삭제로 지울 수 있습니다.

          PRIVACY

          개인정보 및 광고 안내

          현재 이 사이트는 회원가입이나 자체 서버 전송 없이 동작합니다. 밴픽과 전황 입력은 브라우저의 localStorage에 저장되며, 사이트 운영자가 그 내용을 별도로 수집하지 않습니다. 브라우저 저장 공간을 지우면 저장된 경기도 삭제될 수 있습니다.

          • 전장 배경과 일부 영웅 이미지는 외부 이미지 서버에서 불러옵니다. 이미지를 표시할 때 해당 서버에 브라우저의 네트워크 요청 정보가 전달될 수 있으며, 해당 서버의 개인정보 처리 방식은 각 제공자의 정책을 따릅니다.
          • 현재 페이지에는 Google AdSense 광고 코드가 설치되어 있지 않으며, 광고 쿠키나 광고 측정 기능도 이 사이트가 직접 설정하지 않습니다.
          • 향후 AdSense를 적용하면 Google 및 파트너가 광고 게재·측정을 위해 쿠키 또는 유사 기술을 사용할 수 있습니다. 광고를 게시하기 전에 Google의 관련 개인정보 안내와 적용 지역의 동의 요건을 확인하고, 이 안내도 실제 적용 내용에 맞게 갱신하겠습니다.
          • 오류 신고나 개선 의견은 GitHub 이슈 페이지로 보내 주세요. 신고 내용에 개인정보나 계정 정보를 포함하지 마세요.

          광고 게재 여부와 AdSense 승인은 Google의 심사 및 정책에 따르며, 이 안내나 도구의 기능이 승인을 보장하지는 않습니다.
