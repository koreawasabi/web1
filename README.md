# 히오스 전략 코치

Heroes of the Storm 경기에서 전장과 밴픽, 양 팀의 전황을 입력하고 규칙 기반의 다음 행동 추천을 확인하는 정적 웹사이트 MVP입니다.

## 실행

- `index.html`을 브라우저에서 직접 열거나 저장소 루트에서 `python3 -m http.server 8000`을 실행한 뒤 `http://localhost:8000`에 접속하세요.
- 입력 내용은 브라우저의 `localStorage`에 저장되며, 같은 브라우저와 기기에서 다시 열면 이어서 사용할 수 있습니다.

## 현재 범위

- 전장과 선픽/후픽 선택, 양 팀 3밴·5픽 입력, 영웅 중복 선택 방지
- 밴픽 픽을 전황 입력의 영웅 칸에 자동 반영
- 양 팀 5명의 생존/사망, 사망 시 부활 시간, 아군 주요 궁극기 상태, 레벨 및 오브젝트 입력
- 생존 인원, 부활 시간, 레벨, 오브젝트 상황에 따른 일반 규칙 기반 추천 및 상세 입력 요약

맵별/영웅별 조합 분석이나 승률 데이터, 게임 클라이언트 연동, AI API는 포함하지 않습니다. 알 수 없는 전황은 승리 조건처럼 단정하지 않고 안전한 행동을 우선 안내합니다.

## 배포

빌드 단계가 없는 정적 HTML이라 `index.html`을 배포할 수 있습니다. 이 MVP는 Cloudflare Pages나 GitHub의 배포 설정을 추가하거나 변경하지 않습니다.
