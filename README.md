# 히오스 전략 코치

Heroes of the Storm 경기에서 전장과 밴픽, 양 팀의 전황을 입력하고 규칙 기반의 다음 행동 추천을 확인하는 정적 웹사이트 MVP입니다.

## 실행

- `index.html`을 브라우저에서 직접 열거나 저장소 루트에서 `python3 -m http.server 8000`을 실행한 뒤 `http://localhost:8000`에 접속하세요.
- 입력 내용은 브라우저의 `localStorage`에 저장되며, 같은 브라우저와 기기에서 다시 열면 이어서 사용할 수 있습니다.

## 현재 범위

- 첫 화면에서 전장과 선픽/후픽, 양 팀 밴·픽을 한 번에 입력하는 게임 준비 화면
- 전장을 선택하면 해당 전장 이미지가 페이지 배경에 표시되며, 선택 내용과 함께 자동 저장
- 선택한 전장의 목표·라인 구조를 바탕으로 추천 영웅과 우선순위를 낮춰 고려할 영웅 안내
- 검색 가능한 영웅 선택, 잘아타스 포함, 밴·픽 간 중복 선택 방지
- 준비 화면과 게임 중 전황 화면 전환 및 밴픽 수정 동선
- 밴픽 픽을 전황 입력의 영웅 칸에 자동 반영
- 게임 중 양 팀 현재 레벨, 오브젝트 입력을 상단에 두고 생존 상태를 나란히 표시
- 양 팀 5명의 생존/사망, 부활 시간, 주요 궁극기 상태 입력
- 양 팀 현재 레벨 차이와 1·4·7·10·13·16·20 특성 구간, 생존 인원, 부활 시간, 오브젝트까지 남은 시간을 반영한 일반 규칙 기반 추천
- 오브젝트 시점에 부활 시간을 기준으로 양 팀의 예상 합류 인원을 계산하며, 부활 시간이 비어 있으면 확정 인원과 추정 범위로 표시
- 생존·예상 합류 인원, 특성 열세, 오브젝트 상황, 궁극기 참고 순으로 우선순위를 적용한 추천과 판단 근거·주의·추가 입력 안내
- 일부 영웅의 궁극기 교전 영향 잠재력을 보조 판단에 사용하며, 선택 궁극기·실제 재사용 대기시간·미등록 영웅의 영향은 확정하지 않음
- 초반 경험치 수급, 특성 구간 우위, 후반 오브젝트 위험을 시점에 따라 다르게 안내
- 추천 행동과 양 팀 생존 인원 우열을 색상으로 강조해 표시
- 게임 중 추천에 상황 진단, 우선순위·분야 배지, 판단 근거와 입력 정보 충실도 표시
- 추천은 입력된 전황에 대한 규칙 기반 참고이며, 승률이나 실제 경기 데이터를 근거로 하지 않음

맵별/영웅별 조합 분석이나 승률 데이터, 게임 클라이언트 연동, AI API는 포함하지 않습니다. 부활 기반 합류 인원은 위치와 부활 후 이동 시간을 반영하지 않은 추정치입니다. 레벨·특성 안내는 입력된 양 팀 레벨과 일반적인 특성 구간에 따른 규칙 기반 참고입니다. 궁극기 영향도는 일부 영웅에 대한 대략적인 교전 기여 추정이며 선택한 궁극기 자체를 식별하지 않습니다. 기존 저장 데이터는 계속 불러올 수 있고, 예전 버전의 기본 부활 시간 0초는 입력되지 않은 값으로 처리합니다. 알 수 없는 전황은 승리 조건처럼 단정하지 않고 추가로 필요한 정보를 표시합니다.

전장 배경 이미지는 히오스 위키의 이미지 CDN에서 불러오므로 표시할 때 인터넷 연결이 필요합니다.
게임 중 영웅 초상화도 외부 이미지 CDN에서 불러옵니다. 생존/사망은 두 버튼으로 바로 전환할 수 있습니다.

## 배포

`master` 브랜치에 변경 사항을 push하면 GitHub Actions가 `index.html`을 GitHub Pages에 자동 배포합니다. 저장소 설정에서 Pages의 배포 소스가 GitHub Actions로 지정되어 있어야 합니다.
